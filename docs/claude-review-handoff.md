# Claudeレビュー用 引継ぎ資料（Scrum Guide）

## 1) 目的
- このプロジェクトを Claude にレビューしてもらい、UI/UX・実装品質・保守性をブラッシュアップする。
- 仕様書準拠の完成度を上げる（特に「見た目の精度」と「実装の整理」）。

## 2) リポジトリ情報
- GitHub: `https://github.com/b-w-hiroki/scrum-guide`
- 公開URL: `https://b-w-hiroki.github.io/scrum-guide/`
- 技術: React + Vite + Tailwind CSS

## 3) 現状サマリ
- 仕様書セクション8の順番で、主要コンポーネントは一通り実装済み。
- データは `src/data/scrumData.js` に集約済み。
- ページ構成はシングルページ、アンカーリンクで各セクション移動。
- GitHub Pages デプロイは Actions で自動化済み。

## 4) 主なファイル
- レイアウト入口: `src/App.jsx`
- コンポーネント群: `src/components/*.jsx`
- データ: `src/data/scrumData.js`
- Tailwind設定: `tailwind.config.js`
- Pagesデプロイ: `.github/workflows/deploy-pages.yml`

## 5) Claudeに依頼したいレビュー観点
1. **仕様準拠の精度**
   - 各セクションの要件漏れ有無
   - 仕様のニュアンス（見た目・操作感）とのズレ
2. **UI/UX改善**
   - 余白・タイポ・視線誘導・コントラスト
   - モバイルでの可読性、タップしやすさ
3. **コンポーネント設計**
   - 再利用性・責務分離・命名の妥当性
   - 共通UI化できる部分（カード、バッジ、セクションヘッダなど）
4. **アクセシビリティ**
   - 見出し構造、ボタン/リンクの意味、キーボード操作
   - 色依存の情報伝達の有無
5. **パフォーマンス/保守性**
   - 不要レンダリング、データ定義の扱い、将来拡張しやすさ

## 6) 具体的なブラッシュアップ候補
- `Navbar`:
  - アクティブセクション表示（スクロール連動）
  - モバイルメニューの開閉アニメーション改善
- `Hero`:
  - 視覚的な主役感強化（背景表現・CTAの優先度）
- `TermsSection`:
  - カード高さの揃え、読みやすい行間調整
- `ProcessSection`:
  - タイムラインの視認性向上（線・番号・余白）
- `PracticalSection`:
  - タブ選択状態の強調とフォーカス可視化
- `CompaniesSection`:
  - フィルタUIの説明性向上、カテゴリ表記の日本語化
- 全体:
  - セクション共通スタイル抽出
  - アニメーションを最小限追加（過剰にしない）
